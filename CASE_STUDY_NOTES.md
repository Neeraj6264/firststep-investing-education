# Groww FirstStep case-study writing prompts

Use these prompts to write your own 300–700-word case-study page. Choose evidence and phrasing that reflect your own reasoning; this file is a set of questions, not a submission-ready essay. Describe the work as an independent concept inspired by Groww, not an official Groww product.

## Problem interpretation

- What makes a first investing experience feel confusing or high-stakes to a 20–26-year-old?
- Which parts of the challenge are about knowledge, confidence, choice overload, or access?
- What did you assume because no user research or analytics were supplied?

## Users and scope

- Which needs differ for a student, a first-salary earner, and a part-time worker?
- Why does the prototype collect only broad, optional learning preferences?
- Which needs did you prioritize in the welcome flow, learning hub, goal planner, and virtual portfolio?
- What stayed out of scope (for example, live prices, brokerage, identity checks, personalized advice, and real transactions), and why?

## Solution rationale and trade-offs

- How does “learn, plan, practise” connect the screens into one beginner journey?
- Why use fictional fixed-price assets and label them repeatedly?
- What trade-offs came from storing state only in localStorage?
- How do the savings estimate and virtual P/L explain assumptions without promising outcomes?
- Which accessibility and small-screen decisions make the product easier to use?

## Success metrics

- Which leading indicators might show that beginners understand concepts (lesson completion, quiz retries, return visits, or confidence feedback)?
- How would you measure whether a goal planner helps users make realistic plans?
- What guardrail metrics could reveal confusion between simulated and real performance?
- How would you test these measures with users before building a real financial product?

## Learnings and next steps

- What would you validate first with students and first-salary earners?
- Which screen or assumption would you change after observing users?
- What legal, privacy, security, or suitability work would be necessary before any live financial service?
- What did you learn about balancing encouragement with honest risk communication?
